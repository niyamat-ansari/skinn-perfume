# SKINN Silk Rose — Premium Product Landing Page

> **Project Assignment for Acdyon Technologies — Frontend Challenge**

A premium, responsive landing page designed for **SKINN Silk Rose Eau de Parfum**, focusing on visual storytelling, product presentation, performance, and a clear conversion journey.

## 🌐 Live Demo

**https://skinn.niyamat.me/**

## 📌 About

This project was created for **Acdyon Technologies — Part 2: The Premium Home Page**.

The goal was to create a product-focused landing page capable of capturing a user's attention within the first few seconds and encouraging them to explore the product.

The design follows a simple philosophy:

> **Simple. Elegant. Fast. Product-focused.**

Instead of creating a generic e-commerce page, the experience focuses on the fragrance itself through strong visual hierarchy, premium typography, product imagery, fragrance storytelling, interactive selection, and clear calls to action.

## ✨ Features

- Premium hero section
- Responsive mobile and desktop design
- Fragrance story and product presentation
- Fragrance notes
- Interactive product/size selection
- Dynamic pricing
- How-to-wear section
- Smooth navigation and scroll interactions
- Subtle animations
- Clear reservation CTA
